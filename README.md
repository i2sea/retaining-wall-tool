# 옹벽 설계도구 · KDS 대조본

역T형 · L형 · 역L형 옹벽의 구조계산과 도면을 한 화면에서 만드는 단일 HTML 도구입니다.
형상·배근·도면 표현은 2008 도로옹벽 표준도를, 부재·안정 검토는 현행 KDS(KDS 11 80 05, KDS 14 20 xx)를 따릅니다.

## 사용법
claude.ai 아티팩트로 엽니다. 로컬에서는 이 폴더를 웹 서버로 띄워 `index.html`을 엽니다 (예: `python3 -m http.server` 후 http://localhost:8000). 3D 모델·엑셀·압축 기능은 CDN 라이브러리를 불러옵니다.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구성(입력칸·탭) |
| `style.css` | 스타일 |
| `js/wall-core.js` | 철근 규격 · 계산 모델(형상·배근 배치) · 토압(시행쐐기법) · 안정 · 단면 검토 |
| `js/wall-draw.js` | 2D 도면 모델 · 단면력도 · 응력분포도 · 하중 작용도 · 지반반력도 · 설계강도 포락선 |
| `js/wall-cad.js` | DXF(R12) · 3D 뷰(three.js) |
| `js/wall-report.js` | 철근재료표·가공조립표 등 표 · 요약 · 엑셀 · 구조계산서(화면·워드) |
| `js/wall-assist.js` | 일반도 치수 직접 수정 · 후보 배근 자동 선택 · N.G 해결 팁 · 여유 치수 제안 |
| `js/wall-store.js` | 저장·불러오기(계정 저장소·파일) · 구글 드라이브 저장 |
| `js/wall-sheet.js` | 상세도 시트(A3) |
| `js/app.js` | 실행 · 여러 옹벽(프로젝트) · 도면(PDF)에서 옹벽 불러오기 · 시작 |

스크립트는 위 순서대로 불러오며 전역을 함께 씁니다(모듈 import 아님). 뒤 파일의 함수를 앞 파일이 **불러올 때 바로** 호출하면 안 됩니다(이벤트·계산 중 호출은 괜찮음).

## 회귀 비교
`tools/regress.py`: 저장된 작업 묶음(.json)의 옹벽마다 각 탭 화면·DXF 결과 해시를 뽑습니다. 고치기 전후 결과를 비교해 의도하지 않은 변화가 없는지 확인합니다.

## 저장
위쪽 "전체 옹벽 저장 · 불러오기" 창에서 형식(역T형·L형·역L형)과 관계없이 옹벽 전부를 한 묶음으로 저장합니다.
- 구글 드라이브: "내 드라이브 › - GitHub 작업 - › 옹벽 설계도구" 폴더에 `.wall.json` 파일 (불러오기·덮어쓰기·삭제)
- 이 PC(하드디스크): `.json` 파일로 저장 · 파일 열기
- claude 계정 저장소 (claude.ai에서 열었을 때)

## 출력
- 일반도 · 배근도 · 상세도(A3) · 3D 모델
- 철근재료표 · 가공조립표 · 단위수량산출서(.xlsx)
- 안정검토 · 응력분포도 · 구조계산서(.docx)
- CAD 도면(.zip: DXF, 3D LISP)
